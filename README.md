# FORGE — Fitness Store

A fitness store website built with React. Supplements, gear, and the full shopping flow — frontend only, no backend. Accounts, cart and orders are all saved in the browser (localStorage), so everything works without a server.

## What's inside

- Home, Shop and product pages — 24 products with prices, discounts and ratings
- Search, category/price filters and sorting
- Cart and wishlist, with promo codes (try `FORGE10` at the cart)
- Login / signup, and a personal dashboard after login
- Checkout flow and order history

**Demo login:** `demo@forge.fit` / `demo123` (or just sign up — it works too)

## Run it

```bash
npm install
npm run dev
```

## Made with

React + Vite, React Router for pages, plain CSS for styling. Product data lives in `src/data/products.js`.
